🌐 How to Create Your About Page

This guide explains how Application Administrators can create a professional About Page using ChatGPT AI, save it as about.html, and upload it into the correct system location.

📘 Simple Administrator Process

Step 1 — Open ChatGPT

Open ChatGPT and ask AI to generate a professional HTML About Page.

Step 2 — Copy the AI Instruction Template

Copy the AI instruction template below and send it to ChatGPT.

Step 3 — Save the File

Save the generated file exactly as:

about.html

Step 4 — Upload File

Upload and replace the existing file in the following location:

wwwroot/Files/about.html

Step 5 — Open Document Viewer

Finally navigate to:

/document-viewer
🤖 AI Instruction Template

Copy the following template and send it to ChatGPT.

Create a professional responsive HTML About Page for our company. Company Name: XCustomer Requirements: • Modern enterprise layout • Responsive design for desktop, tablet, and mobile • Glass-style card-based layout • Professional gradients and colorful sections • Modern fonts and icons • Academic and technology services • Student support information • Cloud and AI services • Certification and training services • About company section • Vision and mission section • Contact information section • Embedded YouTube video section • Sinhala and Tamil information sections • Footer section • Professional animations and shadows Style: • Professional enterprise UI • Microsoft-style modern design • Rounded cards • Clean spacing • Blue gradient theme • Card-based sections Output: Generate FULL .html file only.
📂 About Page Content Ideas

🎓 Academic Services

Add courses, certifications, cloud learning, student support, and education services.

☁️ Technology Services

Include Microsoft Azure, AI services, cloud infrastructure, and enterprise solutions.

🌍 Multilingual Sections

Add Sinhala and Tamil information for local users and students.

🎥 Video Content

Add YouTube videos for company introduction or training information.
