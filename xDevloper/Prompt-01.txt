# PROJECT

Build a brand-new **Enterprise Learning Content Portal** for the MITANZ360EDU LMS.

The portal will replace the current document viewing experience with a modern Microsoft-style Learning Portal.

The final solution must feel similar to Microsoft 365, Microsoft Learn, Microsoft Loop, SharePoint Modern UI, Visual Studio Code Explorer and Adobe Acrobat Reader combined into one seamless application.

The application is built using:

* .NET 10 Blazor Server
* ASP.NET Identity
* Microsoft Graph SDK v6
* SharePoint Online
* SQL Server
* Bootstrap 5
* Radzen Components
* Fluent Design
* C#
* Dependency Injection
* Async/Await

# VERY IMPORTANT

The end user DOES NOT have a Microsoft account.

The end user signs into ONLY the LMS.

Never require:

* Microsoft Login
* Azure Login
* Office Login
* SharePoint Login

The user may have:

* Gmail
* Yahoo
* Hotmail
* Outlook.com
* Company Email
* Any Private Email

The application authenticates to SharePoint using Microsoft Graph App-Only authentication.

The browser must NEVER communicate directly with SharePoint.

Never expose SharePoint URLs to the client.

All SharePoint communication must occur server-side.
